# 🚀 Планировщик задач (TODO API)

## 📌 Описание
REST API сервер для управления задачами с:
- JWT-аутентификацией
- Поддержкой повторяющихся задач
- SQLite хранилищем
- Готовым фронтендом

## ✅ Выполненные задания со звёздочкой
1. **Гибкая конфигурация через переменные окружения**:
   - `TODO_PORT` - порт сервера
   - `TODO_DBFILE` - путь к файлу БД
   - `TODO_PASSWORD` - пароль для доступа

2. **Расширенные правила повторений**:
   - Еженедельные задачи (`w 1,3,5`)
   - Ежемесячные задачи (`m 15` или `m -1` для последнего дня)
   - Комбинированные правила (`m 10 1,6` - 10 января и июня)

3. **Поиск задач**:
   - По тексту в заголовке/комментарии
   - По дате в формате `DD.MM.YYYY`

4. **Docker-развёртывание**:
   - Мультистейдж сборка
   - Поддержка монтирования БД

5. **JWT-аутентификация**:
   - Защищённые endpoint'ы
   - Валидация токенов

## 🚀 Быстрый старт

### Локальный запуск
1. Установите зависимости:
   ```bash
   go get modernc.org/sqlite
2. Создайте файл .env:
   ```ini
   TODO_PORT=7540
   TODO_DBFILE=scheduler.db
   TODO_PASSWORD=ваш_пароль
3. Запустите сервер:
   ```bash
   go run main.go
4. Откройте в браузере:
   ```
   http://localhost:7540

## 🐳 Docker-образ и развертывание
Особенности реализации:
- Двухэтапная сборка (builder + runtime)
- Alpine Linux для минимального размера
- Автоматическое создание БД при первом запуске
```dockerfile
FROM golang:1.21 AS builder
...
FROM alpine:latest
...
```
Docker-развертывание:
1. Соберите образ:
   ```bash
   docker build -t todo-server .
2. Запустите контейнер:
   ```bash
   docker run -d\
   -v $(pwd)/.env:/app/.env\
   -p 7540:7540\
   -v $(pwd)/scheduler.db:/app/data/scheduler.db\
   -e TODO_DBFILE=/app/data/scheduler.db\
   --name todo-server\
   todo-server
## 🧪 Тестирование
Настройте параметры в tests/settings.go:
   ```go
   var (
    Port = 7540          // Порт сервера
    DBFile = "test.db"   // Тестовая БД
    FullNextDate = true  // Проверка всех правил повторений
    Search = true        // Тестирование поиска
    Token = "ваш_токен"  // Для авторизованных тестов
    )
   ```
Запуск тестов:
```bash
go test -v ./tests
```
